# 截图放这里

这个文件夹是空的，需要你自己截图放进来。

至少放 **2 张**（标 ★ 的），建议放 5 张。

---

## 必需截图

### ★ 1. `03-after-mainmenu.png` — 修复后的游戏主菜单

**内容**：游戏主菜单正常显示，画面铺满整个屏幕，不花屏。
**为什么必须**：这是「真的修好了」的直接证据。
**怎么截**：`Win + Shift + S` 或 `Win + PrtSc`（自动存到图片\屏幕截图）

### ★ 2. `05-game-folder.png` — 游戏目录文件列表

**内容**：在资源管理器里打开游戏目录，能看到 `gcii.exe`、`d3d9.dll`、
`dxgi.dll`、`dxvk.conf` 都在同一层，其他原版文件整齐排列。

**怎么截**：
1. Steam 库 → 右键 Ground Control II → 管理 → 浏览本地文件
2. 在地址栏上方右键 → 勾选「**详细信息**」，能看到大小和修改日期更好
3. 截图

**为什么必须**：这张图直接回应「会不会改坏游戏」的疑虑，非常加分。

## 可选截图（有更好）

### 3. `01-before-artifacts.png` — 修复前的花屏

**内容**：竖条彩虹花屏铺满屏幕。
**注意**：如果你当时没截，可以跳过，或从旧的聊天记录里找。

### 4. `02-before-blackscreen.png` — 修复前的黑屏卡死

**内容**：任务管理器里 `gcii.exe` 在运行，但屏幕上什么都没有。

### 5. `04-ingame-resolution.png` — 游戏内分辨率设置

**内容**：游戏内「视频设置」，把分辨率下拉框展开，显示 5 项低分辨率。
**为什么建议**：主动展示这个限制，比被人在评论里指出来显得更诚实专业。
可以配一句说明：`In-game resolution list is limited to 5 entries — a game engine
limitation, not a DXVK issue.`

## 命名规则

必须用这些**英文文件名**（README 里已经引用好了）：

```
01-before-artifacts.png
02-before-blackscreen.png
03-after-mainmenu.png
04-ingame-resolution.png
05-game-folder.png
```

格式用 **PNG**。

---

## 注意事项

| 事项 | 说明 |
|---|---|
| **用你自己截的图** | 不要用游戏官方宣传图（版权风险） |
| **不要露出个人信息** | 截图前留意：任务管理器可能露出你的用户名；\n资源管理器路径栏可能露出你的盘符和文件夹名 |
| **裁掉敏感区域** | 用画图 / Snipaste 裁掉任务管理器里的用户名列 |

**重点**：`05-game-folder.png` 那张，截图前把地址栏的
`E:\Program Files (x86)\Steam\steamapps\common\Ground Control II`
**裁掉**，只留文件列表部分。默认路径不是隐私，但你的自定义盘符是。
